# Legacy Knowledge Base

**Статус:** архивная независимая реконструкция HOS.

Этот раздел предназначен для хранения базы знаний, созданной другим LLM по тем же исходным материалам HOS.

## Правила использования

- Legacy KB **не является актуальным каноном HOS**.
- Её назначение — поиск исходных идей, терминов, связей, исторических формулировок и указателей на первоисточники.
- При расхождении с актуальной HOS KB приоритет имеет текущий канон.
- Существенные противоречия между Legacy KB и текущей моделью следует проверять по первичным материалам.
- Содержимое импортированных Legacy-файлов следует сохранять без смыслового редактирования, чтобы база оставалась независимым историческим слепком.

## Архитектура знаний

Первичные материалы → Legacy KB (независимая реконструкция) → актуальная HOS KB (канон).

## Источник

Импортируется из архива `happiness-knowledge-base-main`, предоставленного автором HOS 7 октября 2026 года.
