# Научная проверка фреймов — реестр

**Статус:** рабочий эмпирический реестр  
**Дата первого аудита:** 2026-09-01  
**Пересмотр критерия СУТ:** 2026-09-01  
**Объект:** актуальный каталог F01–F34

## Методологическое правило

Этот файл не доказывает HOS как теорию и не отождествляет **СУТ** с каким-либо одним научным конструктом. Внешняя литература обычно измеряет mood / affect, positive affect, negative affect, state anxiety, stress, subjective well-being, fatigue, arousal, engagement, performance и другие показатели.

### Критическое уточнение после H-SUT-01

Предыдущая версия этого реестра ввела два канала — `H` (hedonic) и `I` (instrumental) — как будто функциональная адекватность состояния является самостоятельным компонентом СУТ. Это было **слишком сильным архитектурным выводом** и теперь отменено.

Текущая рабочая модель:

- субъективная приятность/позитивность состояния релевантна СУТ: при прочих равных более приятное состояние имеет более высокий СУТ;
- реактивный фрейм применяется после уже произошедшего снижения СУТ;
- действие внутри реактивного фрейма само может быть неприятным;
- успешное решение внешней проблемы, performance, goal attainment или мобилизация могут быть **механизмом**, через который СУТ затем восстанавливается;
- однако успешность действия сама по себе **не является доказательством повышения СУТ**;
- минимальный критерий успешного реактивного фрейма — компенсация снижения СУТ и возвращение как минимум к типичному для человека состоянию; более сильный результат — повышение выше него.

Динамическая схема реактивного фрейма:

`типичный СУТ → событие/реакция → снижение СУТ → реактивный фрейм → восстановление/повышение СУТ`.

Поэтому научная публикация считается:

- **A — прямой поддержкой**, если экспериментально проверяется близкая к фрейму локальная операция и показано изменение состояния, соответствующее функции фрейма; для реактивного фрейма особенно значимо восстановление состояния после его предварительного ухудшения;
- **B — косвенной поддержкой**, если подтверждается близкий механизм, но не точная операция HOS, либо показана успешность поведения без достаточных данных о последующем восстановлении состояния;
- **C — смешанными/ограничивающими данными**, если эффект зависит от контекста, отложен, неоднороден или имеются существенные отрицательные результаты;
- **D — прямых достоверных данных не найдено** в текущем поиске.

Отсутствие доказательств не означает доказательство неэффективности. Аналогично наличие косвенной поддержки не означает, что конкретный фрейм HOS доказан.

## Коррекция интерпретации существующего аудита F01–F34

Ниже зафиксирована коррекция к уже собранным публикациям. Сами публикации и исходные оценки сохраняются как история аудита; меняется способ их интерпретации относительно СУТ.

### Проактивные фреймы

Для F01–F20 и F32–F34 данные по mood, affect, subjective well-being, stress, anxiety, pleasure, interest и близким субъективным состояниям остаются непосредственно релевантными. Данные по performance, engagement, goal attainment и другим поведенческим исходам могут усиливать механизм-поддержку, но не должны автоматически трактоваться как самостоятельный компонент СУТ.

Особенно это меняет интерпретацию:

- **F09 «Найти смысл в правиле»** — internalization подтверждает механизм, но без изменения субъективного состояния остаётся косвенной поддержкой повышения СУТ.
- **F11 «Игрифицировать»** — motivation/engagement релевантны как механизм, но не тождественны СУТ.
- **F16 «Генерация гнева»** — исследования instrumental anger подтверждают, что гнев способен быть полезным для выполнения некоторых задач. Это поддерживает ресурсную функцию гнева, но **не является прямым доказательством повышения СУТ**. Для проактивного F16 необходимы данные об итоговом изменении субъективного состояния. Поэтому прежняя формула «B для инструментальной части СУТ» отменяется: корректно говорить `B для ресурсного механизма; C/D для повышения СУТ в общем диапазоне F16`.

Tamir M, Ford BQ. *When feeling bad is expected to be good: emotion regulation and outcome expectancies in social conflicts*. Emotion, 2012. DOI: 10.1037/a0024443. https://pubmed.ncbi.nlm.nih.gov/21728413/

### Реактивные фреймы F21–F31

Для реактивного фрейма доказательство должно по возможности соответствовать полной последовательности: исходное/типичное состояние → ухудшение вследствие ситуации → применение операции → восстановление состояния.

Поведенческий результат без последующего восстановления состояния считается **механизм-поддержкой**, а не прямым доказательством повышения СУТ.

- **F21 «Бить не будут»** — cognitive reappraisal поддерживает механизм переоценки угрозы; точная формула и возвращение СУТ к типичному уровню не проверены. Статус `D/B` сохраняется.
- **F22 «Будьте любезны»** — данные о constructive communication/receptiveness подтверждают возможный механизм изменения взаимодействия. Без данных о восстановлении состояния применяющего это `B- для механизма / D для точной техники`, а не прямое подтверждение СУТ.
- **F23 «Какие милые люди»** — cognitive reappraisal непосредственно релевантен, поскольку коммуникация уже закончена и операция направлена на изменение продолжающейся негативной реакции. `B` сохраняется.
- **F24 «Перенос центра коммуникации на собеседника»** — high-quality listening/receptiveness подтверждают соседний механизм управления коммуникацией, но успешное изменение разговора само по себе не доказывает восстановление СУТ. `B для механизма / D для точной процедуры`.
- **F25 «Плохо — это хорошо»** — reappraisal имеет данные по эмоциональным outcomes, поэтому остаётся одной из наиболее близко поддержанных реактивных операций: `A-/B+`.
- **F26 «ПВБ»** — distraction поддерживает эмоциональную регуляцию; suppression не поддержан. `C/B` сохраняется.
- **F27 «Все будет хорошо / Этого не случится»** — positive future imagery имеет данные по positive affect/anxiety/distress, поэтому `A- для близкого механизма` сохраняется. Успешное прохождение экспозиции является дополнительным, но не определяющим результатом.
- **F28 «Перехват страха и гнева»** — distraction и снижение arousal поддерживают регуляцию состояния. Формулировка «не дать эмоции сорвать действие» больше не используется как самостоятельный критерий СУТ. `B+` для механизма сохраняется.
- **F29 «Выговорить переживание»** — данные остаются смешанными и преимущественно отсроченными: `C/B-`.
- **F30 «Прошлое не релевантно»** — reappraisal, acceptance и self-distancing поддерживают снижение distress/rumination и поэтому релевантны восстановлению состояния. Точная развилка HOS не проверена: `B для механизма / D для точной развилки`.
- **F31 «Изменение прошлого»** — imagery rescripting имеет близкие данные по снижению эмоционального дистресса и симптомов; `A для близкой клинической техники` сохраняется.

## Что изменилось архитектурно

1. **Отменено представление I/functionality как самостоятельного компонента СУТ.** Оно было введено преждевременно.
2. **Разделены результат действия и результат фрейма.** Решение задачи может быть механизмом, но результат реактивного фрейма оценивается по восстановлению СУТ.
3. **Реактивный фрейм получил динамический критерий.** Он начинается после снижения СУТ и должен как минимум компенсировать это снижение.
4. **Неприятность процесса допустима.** Фрейм может временно требовать неприятного действия, если итогом является восстановление/повышение СУТ.
5. **F16 возвращён к более строгой интерпретации.** Инструментальная полезность гнева подтверждает ресурсный механизм, но не повышение СУТ как таковое.

## Следствие для дальнейшей проверки

Для проактивного фрейма основной эмпирический вопрос: **повышает ли локальная операция СУТ относительно состояния до её применения?**

Для реактивного фрейма основной вопрос: **после вызванного ситуацией снижения СУТ позволяет ли локальная операция компенсировать это снижение и вернуть СУТ как минимум к типичному уровню?**

Пока СУТ не имеет собственной валидированной шкалы, внешние показатели mood, affect, distress, anxiety, stress, subjective well-being и другие используются только как частичные прокси. Поведенческие показатели используются для проверки механизма, но не заменяют измерение состояния.
