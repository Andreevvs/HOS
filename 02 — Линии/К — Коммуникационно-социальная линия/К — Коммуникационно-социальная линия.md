# К — Коммуникационно-социальная линия

**Статус:** рабочая каноническая заметка

Коммуникационно-социальная линия описывает развитие способов смыслового обмена и организации взаимодействия между собственной волей/позицией, волей и позициями других людей и общей целью.

| Код | Рабочее название | Первая целостная форма |
|---|---|---|
| К1 | Базовый смысловой обмен | L1 |
| К2 | Тоталитарная коммуникация | L2 |
| К3 | Авторитарная коммуникация | L3 |
| К4 | Демократичная коммуникация | L4 |
| К5 | Коммуникация с позиции третьего лица | L5 |
| К6 | Коммуникация с позиции четвёртого лица / конкордантная коммуникация | L6 |
| К7 | предельная коммуникационная функция | не формализовано |

## Архитектурное правило

Для К-линии подтверждена треугольная структура уровневых форм:

`К1: L1–L6`  
`К2: L2–L6`  
`К3: L3–L6`  
`К4: L4–L6`  
`К5: L5–L6`  
`К6: L6`

Голографичность не означает существование каждого метанавыка на каждом уровне. Компоненты будущей функции могут формироваться раньше, но обозначение `Кn@Lm` используется только там, где целостная функция Кn уже имеет смысл.

После появления целостной функции её дальнейшее вертикальное развитие может проявляться не только в усложнении внутреннего механизма, но и в способности сохранять адекватность функции во всё более разнообразной, сложной, неопределённой, масштабной и потенциально опасной среде. **Статус этого обобщения — рабочая гипотеза до проверки на других линиях.**

К-коммуникационно-социальная линия становится необходимой для вертикального развития на L2 — при прохождении кризиса социализации. Это не означает, что К1 начинает развиваться только на L2: К1 имеет полноценную форму уже на L1.

Модель развития Эго Джейн Лёвинджер / Сюзанны Кук-Гройтер используется как сравнительная рамка для перспектив 1-го, 2-го, множественного 2-го, 3-го и 4-го лица, но не отождествляется с метанавыками HOS.
