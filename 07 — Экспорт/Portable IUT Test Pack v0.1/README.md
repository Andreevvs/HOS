# HOS Portable IUT Test Pack v0.1

**Статус:** экспериментальный экспортный слой. Не является частью канона HOS и не изменяет его.

## Цель

Минимальный переносимый набор материалов для проверки, может ли независимая LLM провести диагностику ИУТ/УРЛ по HOS и получить результат, сопоставимый с другими моделями.

## Что входит в пакет

Для теста в новую LLM загрузить ровно три файла:

1. `01 — Канон/Архитектура уровней развития.md`
2. `03 — Диагностика/ИУТ — измерение.md`
3. `07 — Экспорт/Portable IUT Test Pack v0.1/LLM_PROTOCOL.md`

Не загружать блог, курс, транскрипты и другие материалы для первого кросс-модельного теста. Их наличие увеличивает риск того, что модель начнёт реконструировать старые версии методики вместо следования каноническому протоколу.

## Как запускать тест

После загрузки трёх файлов дать модели только фразу:

> Хочу измерить свой ИУТ

Далее отвечать на вопросы естественно, не подстраиваясь под предполагаемый уровень.

## Что фиксировать для сравнения моделей

После завершения диагностики сохранить:

- полный диалог;
- подтверждённый уровень;
- диапазон ИУТ/УРЛ;
- следующий кризис;
- статус перехода к следующему уровню;
- ключевые подтверждающие свидетельства;
- противоречащие или неопределённые свидетельства;
- число заданных вопросов;
- вопросы, которые модель добавила вне банка;
- места, где модель нарушила закон последовательности или преждевременно раскрыла диагностическую логику.

## Критерий успешной переносимости v0.1

Пакет считается практически переносимым, если несколько независимых LLM на одном и том же наборе биографических данных:

1. определяют один и тот же подтверждённый уровень либо соседние уровни с явно указанной неопределённостью;
2. не пропускают проверку нижележащих кризисов;
3. используют биографические свидетельства, а не самооценочные декларации;
4. не выдают псевдоточное значение ИУТ внутри диапазона;
5. сходятся в основных аргументах, объясняющих итог.

Это рабочий критерий инженерной воспроизводимости, а не психометрическая валидация методики.

## Что этот пакет НЕ проверяет

Пакет пока не предназначен для:

- точного позиционирования внутри диапазона ИУТ;
- диагностики К7 / Совершенства;
- вычисления профиля по семи линиям;
- проверки метакомпетенций и голографичности как отдельного формального слоя;
- клинической или медицинской диагностики.

## Версионирование

При изменении канонического файла `ИУТ — измерение.md` или архитектуры уровней Portable Pack должен быть повторно проверен. Экспортный слой не должен содержать конкурирующую копию канона; он только задаёт состав пакета и правила исполнения.
