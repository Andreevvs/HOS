# Курс HOS Intro

**Статус:** рабочая ветка проектирования курса  
**Назначение:** компактно и структурированно сохранить все результаты исследования UYO, Taking It Lightly и проектные решения по HOS Intro.

## Центральная идея

HOS Intro — не «UYO с терминологией HOS». Из UYO и его прямого потомка Taking It Lightly заимствуется прежде всего **experiential-педагогика**: сначала безопасный опыт и обнаружение собственного паттерна, затем понимание и выбор. HOS добавляет карту развития и направленность вперёд.

**Общая дуга:**

> Безопасность → Контакт → Открытость → Разрешение чувствовать → Выражение → Быть увиденным → Быть принятым → Понимание себя → Карта HOS → Ситуация развития → Выбор → Действие.
