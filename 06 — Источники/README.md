# Источники

Здесь хранятся первичные материалы: курс, блог, транскрипты встреч и
другие авторские источники.

**Правило:** утверждение из источника не становится каноном
автоматически. Оно должно быть выделено, классифицировано и при
необходимости проверено.

Рекомендуемые подпапки: `Курс/`, `Блог/`, `Встречи/`.

## Приоритетные исходные опоры текущего этапа

-   курс/блог: исходная шкала F1 ИНЬ/ЯН;
-   транскрипты: принцип пожизненного усложнения метанавыков и
    голографичность;
-   спецификация v0.6: последний монолитный снимок перед атомаризацией.
