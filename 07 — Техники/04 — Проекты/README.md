# Проекты

**Класс:** техника HOS

Проекты — класс технологий HOS, связанных с формированием и реализацией конкретных целей.

Рабочая модель проектного цикла, требующая дальнейшей сверки и формализации по источникам:

**цель → планирование → исполнение → анализ результата → следующий цикл**.

Проект потенциально задействует несколько линий развития и метанавыков; эти связи не следует смешивать с классификацией самой техники.
