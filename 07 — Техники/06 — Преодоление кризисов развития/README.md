# Преодоление кризисов развития

**Класс:** техника HOS

Техники и методики, направленные на прохождение кризисов развития K1–K7 и переход к следующей устойчивой организации развития.

Не предполагается искусственная симметрия «один кризис = одна готовая техника». Степень разработанности техник для разных кризисов в исходных материалах различается и должна фиксироваться явно.

Связь конкретной техники с кризисом хранится отдельно от её возможных связей с линиями и метанавыками.
