# F51 — Выделить защищённое время

**Класс:** фрейм  
**Подтип:** проактивный  
**Линия:** реализационно-достиженческая  
**Уровень / метанавык:** Р1 (рабочая привязка)  
**Статус:** рабочий фрейм, утверждён 2026-08-28

## Назначение

Создать локальное условие для формирования навыка: заранее выделить период, в который человек занимается выбранным навыком и не переключается на конкурирующие действия.

## Ядро процедуры

1. Выбрать формируемый навык.
2. Выделить конкретный период для тренировки.
3. На этот период исключить конкурирующие задачи и переключения.
4. Использовать время по назначению.

## Примеры реализации из материалов HOS

Материалы по формированию навыков предлагают выделять время, когда занимаешься этим навыком и ничем другим.

## Комментарий / зона проверки

Есть существенное сомнение в статусе самостоятельного фрейма: защищённое время может быть элементом ритуала или организации регулярной практики. Пока сохраняется как F, поскольку сама операция может быть выполнена локально и непосредственно поддерживает формирование навыка Р1.

## Границы

Долгосрочное расписание тренировок — уже система практики. F51 описывает локальную операцию выделения и защиты времени.
