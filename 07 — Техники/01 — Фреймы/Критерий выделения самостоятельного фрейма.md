# Критерий выделения самостоятельного фрейма

## Определение фрейма

**Фрейм — локальная техника, применение которой непосредственно изменяет СУТ в конкретной ситуации.**

Изменение СУТ не обязано быть самостоятельной конечной целью применения фрейма. Оно может происходить в процессе решения более сложной задачи — обучения, коммуникации, реализации цели, проекта и т. п. Если локальная операция непосредственно переводит человека в иное субъективное состояние, она может быть фреймом даже тогда, когда это изменение используется как ресурс дальнейшей деятельности.

Краткость, локальность и возможность выполнить действие «здесь и сейчас» сами по себе недостаточны. Если операция непосредственно не изменяет СУТ, а её основная функция — формировать способность / метанавык или решать предметную задачу, она относится к соответствующему классу техник, а не к фреймам.

## Критерий самостоятельного F-кода

Различие внешнего действия само по себе не является основанием для создания нового F-кода.

Новый способ исполнения уже существующего механизма считается **реализацией существующего фрейма**, если сохраняется его основная тренируемая операция и механизм воздействия.

Новый F-код создаётся только тогда, когда кандидат:

1. соответствует определению фрейма — непосредственно изменяет СУТ;
2. содержит **отличающийся механизм / тренируемую операцию**, а не просто иной внешний способ выполнения.

## Требование к карточке конкретного фрейма

Каждая карточка конкретного F должна содержать раздел **«Примеры реализации из материалов HOS»**.

В этот раздел включаются различные конкретные способы исполнения данного фрейма, которые действительно присутствуют в материалах проекта. Примеры не должны придумываться для полноты каталога.

## Следствие для каталога

Несколько конкретных действий могут быть примерами одного фрейма.

Например, в рамках актуального F06 «Позитивный контакт с незнакомцем» в материалах HOS встречаются такие реализации:

- перемигнуться с незнакомцем;
- приятно поговорить с незнакомым человеком;
- подарить цветок незнакомому человеку.

Во всех этих случаях сохраняется одно ядро: инициировать позитивный контакт с незнакомым человеком и получить позитивный возврат коммуникации. Поэтому отдельные F-коды для каждого внешнего действия не создаются.

## Архитектурное назначение

Правило ограничивает бесконтрольное размножение сущностей в каталоге фреймов и отделяет:

- **фрейм** — локальную технику непосредственного изменения СУТ;
- **конкретную реализацию фрейма** — внешний способ выполнения того же механизма;
- **технику формирования метанавыка** — операцию, основная функция которой состоит в развитии способности и которая сама по себе непосредственно СУТ не изменяет.
