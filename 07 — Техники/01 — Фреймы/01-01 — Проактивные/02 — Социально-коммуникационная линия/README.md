# Социально-коммуникационная линия — проактивные фреймы

Навигационный раздел. Канонические карточки не дублируются.

В этот каталог входят только локальные социально-коммуникационные техники, которые **непосредственно изменяют СУТ**. Изменение СУТ может быть встроено в более сложную коммуникационную деятельность, но должно быть необходимой частью механизма фрейма.

## Нормализация 2026-08-29

F35, F37 и F38 исключены из F-каталога: их непосредственная функция состоит в тренировке коммуникативной способности или изменении способа решения коммуникационной задачи; изменение СУТ возможно, но не является необходимой частью механизма.
