# F52 — Встроить навык в ритуал

**Класс:** фрейм (рабочая классификация)  
**Подтип:** проактивный  
**Линия:** реализационно-достиженческая  
**Уровень / метанавык:** Р1/Р2 (рабочая привязка)  
**Статус:** рабочий фрейм, утверждён 2026-08-28

## Назначение

Упростить регулярное формирование навыка, привязав его тренировку к уже существующему ритуалу или устойчивой последовательности действий.

## Ядро процедуры

1. Выбрать навык, который требуется регулярно тренировать.
2. Найти существующий устойчивый ритуал / повторяющуюся последовательность действий.
3. Определить место, где тренировка навыка будет встроена в эту последовательность.
4. Выполнять тренировку как часть ритуала, уменьшая необходимость каждый раз отдельно принимать решение о начале.

## Примеры реализации из материалов HOS

Материалы по Р1 прямо предлагают ритуализировать обучение и включать формирование навыка в существующие ритуалы.

Конкретный бытовой ритуал без подтверждения источником не добавляется.

## Комментарий / зона проверки

Это один из наиболее спорных F-кандидатов. По архитектуре HOS ритуал является отдельным классом и обычно представляет последовательность действий / фреймов. Поэтому F52 впоследствии может быть переклассифицирован из конкретного фрейма в технику конструирования ритуала или формирования навыка. Пока оставляем F-код по авторскому решению этапа инвентаризации.

## Источники HOS

- Материалы HOS по Р1: ритуализировать обучение, встроить формирование навыка в ритуалы.
- Авторское решение 2026-08-28: сохранить как рабочий фрейм, сомнение явно зафиксировать.
