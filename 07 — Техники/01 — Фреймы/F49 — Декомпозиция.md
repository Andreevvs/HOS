# F49 — Декомпозиция

**Класс:** фрейм  
**Подтип:** проактивный  
**Линия:** реализационно-достиженческая  
**Уровень / метанавык:** Р3 (рабочая привязка)  
**Статус:** утверждён как рабочий фрейм 2026-08-28

## Назначение

Преобразовать слишком крупную или трудно реализуемую задачу в набор меньших подпроектов / задач, с которыми можно работать отдельно.

## Ядро процедуры

1. Выбрать крупную задачу, которая плохо переводится в непосредственное действие.
2. Разделить её на меньшие части.
3. Для частей определить собственный наблюдаемый результат / критерий завершения.
4. Выделить часть, с которой можно начать работу.

## Примеры реализации из материалов HOS

Материалы Р3 прямо предлагают разбивать сложный проект на подпроекты и задачи, задавая для них собственные критерии.

Конкретные предметные примеры декомпозиции без подтверждения источником не добавляются.

## Комментарий / зона проверки

Декомпозиция — широко известный инструмент проектного управления и не является специфической разработкой HOS. Поэтому статус самостоятельного F остаётся рабочим. Аргумент за сохранение: HOS использует её как конкретную локальную операцию развития Р3. При последующей нормализации возможно перемещение в инструментарий формирования Р3 без F-кода.
