# Классификация фреймов — рабочая гипотеза

**Статус:** рабочая архитектура, подтверждённая автором; требует проверки на полном каталоге фреймов

## Канонические линии развития

1. Физическая.
2. Социально-коммуникационная.
3. Реализационно-достиженческая.
4. Эмоциональная.
5. Познавательно-творческая.
6. Целостности и воли.
7. Духовная.

## Рабочая архитектура

Фреймы не следует раскладывать по одной взаимоисключающей иерархии. Для техники могут независимо фиксироваться несколько признаков.

### 1. Режим запуска

- активный / проактивный;
- реактивный;
- оба режима.

Активный и проактивный — абсолютные синонимы в HOS.

### 2. Связь с линиями развития

Для проактивных фреймов основной содержательной классификацией является связь с одной или несколькими из семи линий развития. Проактивный фрейм может выступать локальной микротренировкой навыков соответствующей линии.

### 3. Проблемная ситуация и линия её источника

Для реактивных фреймов основной практической классификацией является тип проблемной ситуации, на которую отвечает техника.

Дополнительно может фиксироваться **линия развития, к которой относится источник проблемной ситуации**. Отдельное поле «линия механизма воздействия» не вводится: для текущей архитектуры оно признано избыточным.

Один и тот же реактивный фрейм может применяться к проблемам, возникающим в разных линиях; в таком случае связь с линиями остаётся many-to-many либо определяется на уровне конкретного применения.

### 4. Фреймы утилизации времени

Отдельная функциональная группа: фреймы, используемые для преобразования свободного или вынужденно незанятого времени в ресурс повышения СУТ и/или развития.

### 5. Ритуалы / фрейм-сеты

Отдельная композиционная группа. Ритуал может состоять из одного фрейма, но, как правило, представляет определённую последовательность действий/фреймов, привязанную к повторяющемуся контексту.

Ритуальность не отменяет других признаков: элементы ритуала могут одновременно быть проактивными, относиться к конкретным линиям развития или выполнять функцию утилизации времени.

## Дополнительные механизмы и семейства

Такие обозначения, как «управление эмоциональными состояниями», «изменение ландшафта впечатлений», ПВК, «радость достижения» и т. п., не являются верхним уровнем взаимоисключающей классификации. Они могут фиксироваться как механизм, семейство или функциональная связь техники.

## Результат проверки гипотезы о реактивных фреймах

Классификация реактивных фреймов непосредственно по одной линии развития недостаточна.

- «Бить не будут» связан с проблемной ситуацией страха физической боли: источник проблемы относится к физической линии.
- «Будьте любезны» отвечает на проблему затруднённой коммуникации: источник относится к социально-коммуникационной линии.
- «Какие милые люди» запускается после неудачной коммуникации: источник проблемной ситуации также социально-коммуникационный.
- «Поплакать» и «Прокричаться» могут применяться к напряжению, возникшему из проблем разных линий, поэтому единственная линия не назначается без контекста.

Вывод: **для реактивного фрейма первичным индексом является тип проблемной ситуации; если это полезно и однозначно, дополнительно фиксируется линия источника проблемы.**

## Матрица для дальнейшей разметки

Для каждой конкретной техники проверяются поля:

- режим запуска;
- для проактивного применения — линия(и) развития;
- для реактивного применения — проблемная ситуация / триггер;
- для реактивного применения — линия(и) источника проблемы, если определима;
- принадлежность к утилизации времени;
- участие в ритуале / фрейм-сете;
- механизм / семейство;
- связь с метанавыками (отдельная many-to-many связь).

## Основания

- Канон HOS: «Семь линий развития».
- Авторские уточнения 2026-08-26—27 о классификации проактивных и реактивных фреймов, фреймах утилизации времени и ритуалах.
- Авторское решение 2026-08-27: для реактивных фреймов достаточно фиксировать линию источника проблемы; отдельная линия механизма воздействия не требуется.
