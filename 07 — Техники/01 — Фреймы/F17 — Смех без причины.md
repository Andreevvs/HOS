# F17 — Смех без причины

**Класс:** фрейм  
**Подтип:** активный / проактивный  
**Семейство:** управление эмоциональными состояниями  
**Статус:** утверждённая техника HOS

## Назначение

Произвольно вызвать состояние смеха без необходимости во внешнем смешном стимуле и использовать его для повышения ситуативного тона (СУТ).

## Принцип

Фрейм инициируется самим человеком. Его смысл — не реакция на уже возникшее негативное состояние, а тренировка и использование способности произвольно вызывать эмоциональное состояние, связанное со смехом.

## Процедура

1. Самостоятельно инициировать фрейм, не ожидая внешней смешной ситуации.
2. Начать смеяться без обязательной содержательной причины или внешнего стимула.
3. Поддерживать смех как произвольно вызванное эмоционально-физиологическое состояние в пределах выбранного фрейма.
4. Оценить изменение собственного эмоционального состояния и СУТ.

Конкретные параметры длительности и способы облегчения произвольного вызова смеха в текущих материалах HOS не формализованы и не достраиваются.

## Классификационное уточнение

**«Смех без причины» — проактивный фрейм.** Возможное фактическое улучшение уже существующего негативного состояния не делает его реактивным по классификации HOS: техника определяется способом инициации — человек сам произвольно вызывает смех.
