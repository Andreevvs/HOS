# Фреймы

**Класс:** техника HOS

## Определение

Фрейм — локальное воздействие, предназначенное для изменения ситуативного тона (СУТ) в текущем контексте.

## Архитектурное правило кодирования

**Fxx = только конкретный фрейм.**

Классы, группы, семейства, механизмы и композиционные конструкции F-код не получают.

Поэтому отдельно от нумерованного каталога ведутся:

- [[07 — Техники/01 — Фреймы/Утилизация времени|Фреймы утилизации времени]] — функциональная группа;
- [[07 — Техники/01 — Фреймы/Ритуалы и фрейм-сеты|Ритуалы / фрейм-сеты]] — композиционная группа;
- [[07 — Техники/01 — Фреймы/Управление эмоциональными состояниями|Управление эмоциональными состояниями]] — семейство / механизм;
- [[07 — Техники/01 — Фреймы/Изменение ландшафта впечатлений|Изменение ландшафта впечатлений]] — семейство;
- [[07 — Техники/01 — Фреймы/Позитивно-возвратная коммуникация|Позитивно-возвратная коммуникация]] — семейство / механизм.

Коды, освобождённые после вывода классификаторов из ряда Fxx, пока **не перенумеровываются**: F-коды рассматриваются как стабильные идентификаторы конкретных техник, а не как порядковая нумерация без пропусков.

## Основная классификация

### Проактивные фреймы

Активный = проактивный. Основная содержательная классификация — по линии развития / виду интеллекта, способность которого человек реализует и локально тренирует при выполнении фрейма.

Общий эффект повышения СУТ сам по себе не означает принадлежности к эмоциональной линии: все фреймы повышают СУТ.

### Реактивные фреймы

Основной индекс — проблемная ситуация / триггер. Дополнительно фиксируется линия источника проблемы, если она определима.

### Фреймы утилизации времени

Отдельная функциональная группа, определяемая контекстом свободного или вынужденно незанятого времени.

### Ритуалы / фрейм-сеты

Отдельная композиционная группа. Ритуал может включать один или несколько фреймов и не отменяет их собственную классификацию.

## Связь с линиями и метанавыками

- Для проактивных фреймов связь с линиями определяется видом интеллекта, способность которого требуется для выполнения фрейма.
- Для реактивных фреймов линия относится к источнику проблемной ситуации.
- Связь с метанавыками хранится отдельно и является many-to-many.

## Принцип ведения каталога

Не создавать отдельную F-карточку для каждого примера реализации. Новая F-карточка появляется, если есть самостоятельный механизм или существенная процедура.

Одно и то же внешнее действие может относиться к разным фреймам в зависимости от функции, а также быть фреймом или перманентной практикой в зависимости от временного горизонта и цели применения.
