# Фреймы

**Класс:** техника HOS

## Определение

Фрейм — **локальная техника, непосредственно изменяющая ситуативный тон (СУТ) в конкретной ситуации**.

Изменение СУТ не обязано быть самостоятельной конечной целью. Оно может происходить как непосредственный промежуточный механизм при решении более сложной задачи.

## Архитектура каталога

Каноническая карточка конкретного фрейма хранится непосредственно в иерархии его основной классификации, а не в общем списке корневой папки.

### 01 — Проактивные

Проактивные фреймы группируются по линии развития / виду интеллекта, способность которого реализуется при выполнении фрейма:

1. физическая;
2. социально-коммуникационная;
3. реализационно-достиженческая;
4. эмоциональная;
5. познавательно-творческая;
6. линия Ц / целостности — содержательная формализация отложена;
7. духовная — содержательная формализация отложена.

Фреймы с двумя режимами, у которых существует самостоятельное проактивное применение, канонически хранятся в проактивной ветке по основной линии. Их реактивное применение фиксируется внутри карточки и в матрице; карточка не дублируется.

### 02 — Реактивные

Реактивные фреймы группируются по линии источника проблемы, если она определима. Для фреймов, применимых к проблемам разных линий, используется раздел **«00 — Межлинейные»**.

### 03 — Утилизация времени

Функциональная группа / контекст использования техник. Действие в этом контексте может быть фреймом, перманентной практикой или иной техникой по собственным критериям класса.

### 04 — Ритуалы и фрейм-сеты

Ритуал — стабильная повторяемая форма организации поведения. Он может включать фреймы, перманентные практики и обычные действия. Сам ритуал автоматически фреймом не становится и F-кода не получает.

## Правило F-кодов после реструктуризации 2026-08-31

По решению автора прежнее правило неизменяемости F-кодов отменено.

**Fxx — последовательный идентификатор актуального конкретного фрейма в текущей иерархии каталога.**

Нумерация идёт сквозным рядом:

1. проактивные фреймы — последовательно по линиям;
2. затем реактивные — по линиям / межлинейной группе.

После реструктуризации активный каталог перенумерован в диапазон **F01–F31 без пропусков**. Старые F-коды сохраняются только в таблице миграции и исторических материалах и больше не являются каноническими идентификаторами.

См. [[07 — Техники/01 — Фреймы/Миграция F-кодов 2026-08-31|Миграция F-кодов 2026-08-31]].

## Принцип выделения фрейма

Не создавать отдельную F-карточку для каждого примера реализации. Различие внешнего действия само по себе не является основанием для нового F-кода. Новый фрейм выделяется только при отличающемся механизме / тренируемой операции, удовлетворяющей определению фрейма.

Одно и то же внешнее действие может относиться к разным техникам в зависимости от функции, а также быть фреймом или перманентной практикой в зависимости от режима применения.

Каждая конкретная F-карточка должна содержать раздел **«Примеры реализации из материалов HOS»**. В него включаются только реально найденные в материалах HOS способы реализации; недостающие примеры не достраиваются.
