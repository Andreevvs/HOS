# Фреймы

**Класс:** техника HOS

Фреймы — короткие воздействия на ситуативный тон (СУТ).

Рабочие подтипы:
- активные / проактивные;
- реактивные;
- фреймы утилизации времени.

В материалах также встречаются фрейм-сеты/ритуалы; их точный статус внутри классификации требует отдельной формализации.

Проактивный фрейм может одновременно служить микротренировкой одного или нескольких метанавыков. Такая связь фиксируется в карточке техники и не меняет её класс.

> Конкретный каталог фреймов будет заполняться после сверки презентаций и блога.
