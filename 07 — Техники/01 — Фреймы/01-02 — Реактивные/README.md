# Реактивные фреймы

Основная классификация реактивных фреймов — **по проблемной ситуации / триггеру**, а не по линии развития. Линия источника проблемы фиксируется как дополнительный атрибут, если она определима.

Необходимый критерий включения в F-каталог: локальная техника должна **непосредственно изменять СУТ**. Решение коммуникационной или иной предметной задачи само по себе недостаточно.

## Исторические пробелы

Коды деклассифицированных F не переиспользуются.

- **F33** — прежняя карточка «Реакция на тоталитарную коммуникацию»: комплексная область формирования коммуникативного метанавыка.
- **F34** — «Сказать нет»: упражнение развития Ф2 «Контроль границ»; обозначение границы само по себе не гарантирует непосредственного изменения СУТ.
- **F36** — «Ты прав»: упражнение изменения когнитивно-коммуникационной позиции в споре; изменение СУТ не является необходимым непосредственным эффектом.

F34 и F36 сохранены в [[07 — Техники/05 — Формирование метанавыков/Упражнения социально-коммуникационной линии|Упражнениях социально-коммуникационной линии]].

Подгруппы по типам проблемных ситуаций будут введены только после завершения нормализации, чтобы не закреплять преждевременную таксономию.
