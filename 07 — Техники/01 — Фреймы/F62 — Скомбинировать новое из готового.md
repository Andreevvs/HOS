# F62 — Скомбинировать новое из готового

**Класс:** фрейм  
**Подтип:** проактивный  
**Линия:** познавательно-творческая  
**Уровень / метанавык:** Т3  
**Статус:** рабочий фрейм 2026-08-28

## Назначение

Тренировать комбинаторную сторону творчества Т3: создать новый вариант, используя уже существующие элементы как детали конструктора.

## Ядро процедуры

1. Выбрать набор доступных готовых элементов / решений / образцов.
2. Не копировать один образец целиком.
3. Изменить сочетание элементов или соединить элементы из разных источников.
4. Получить новую комбинацию, имеющую самостоятельный результат.

## Примеры реализации из материалов HOS

- Конструктор: из заданных готовых деталей собрать что-то новое.
- В материалах творческая сторона Т3 описана через подражание, компиляцию, комбинаторику и конструирование.

## Комментарий / зона проверки

Подражание само по себе не выделяется в отдельный F: простое воспроизведение образца не содержит операции создания новой комбинации. F62 фиксирует именно компиляционно-конструкторский механизм.

## Границы

Создание принципиально нового решения без опоры на готовую комбинационную схему может относиться к более высокому уровню творчества.

## Источники HOS

- Материалы Т3: классификация и комбинаторика; подражание, компиляция, конструирование; образ конструктора из готовых деталей.
