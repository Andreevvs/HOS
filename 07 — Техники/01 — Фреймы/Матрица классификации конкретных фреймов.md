# Матрица классификации конкретных фреймов

**Статус:** рабочая разметка конкретных техник HOS

## Правило

В матрицу входят только конкретные фреймы с F-кодом. Группы, семейства, механизмы и ритуальность как класс ведутся отдельно.

Поля:
- **режим** — проактивный / реактивный / оба;
- **линия** — для проактивного применения: линия(и) развития; для реактивного: линия источника проблемы, если определима;
- **проблемная ситуация** — только для реактивного применения;
- **доп. связь** — семейство / механизм / функциональная группа.

## Что ещё требует проверки

1. Для реактивных универсальных фреймов F01, F02, F09, F15, F16, F19 линия источника проблемы не должна фиксироваться однажды навсегда: она зависит от конкретной ситуации применения.
2. F21, F22, F24 и F25 закреплены за эмоциональной линией по авторским решениям 2026-08-27. Для F21 содержание произведения, а для F22 физическое возбуждение являются средствами реализации и не определяют линию фрейма.

## Вывод

Утверждённая архитектура выдерживает проверку: проактивные фреймы индексируются по линии, на изменение которой направлен фрейм, а не по используемому средству. Реактивные — прежде всего по проблемным ситуациям, а линия источника проблемы добавляется только там, где она определима.
