# Матрица классификации конкретных фреймов

**Статус:** рабочая разметка конкретных техник HOS

## Правило

В матрицу входят только конкретные фреймы с F-кодом. Группы, семейства, механизмы и ритуальность как класс ведутся отдельно.

Поля:
- **режим** — проактивный / реактивный / оба;
- **линия** — для проактивного применения: линия интеллекта, способность которой реализует/тренирует фрейм; для реактивного: линия источника проблемы, если определима;
- **проблемная ситуация** — только для реактивного применения;
- **доп. связь** — семейство / механизм / функциональная группа.

## Принцип отнесения проактивного фрейма к линии

Все фреймы по определению используются для повышения СУТ и поэтому в конечном итоге изменяют эмоциональное состояние. Это **не является основанием автоматически относить их к эмоциональной линии**.

Проактивный фрейм относится к той линии развития / виду интеллекта, способность которой человек реализует и локально тренирует при использовании фрейма.

Пример: F19 «Физическая активация» повышает СУТ и эмоциональное состояние, но способность в любой момент подобрать и использовать подходящую физическую активность относится к физическому интеллекту. Поэтому F19 — фрейм физической линии.

## Что ещё требует проверки

1. Для реактивных универсальных фреймов F01, F02, F09, F15, F16, F19 и F30 линия источника проблемы не должна фиксироваться однажды навсегда: она зависит от конкретной ситуации применения.
2. F21, F22, F24 и F25 закреплены за эмоциональной линией по авторским решениям 2026-08-27. Основание — реализуемая способность эмоционального интеллекта, а не сам факт изменения СУТ.
3. Физический блок на текущем материале разделён на пять ядер: активация, релаксация, управляемый стресс, телесное удовольствие / хорошее самочувствие, дыхательно-голосовая регуляция.
4. Одно и то же внешнее действие может реализовывать разные фреймы в зависимости от функции и может быть либо фреймом, либо перманентной практикой в зависимости от временного горизонта и цели применения.

## Вывод

Проактивные фреймы классифицируются по виду интеллекта, способность которого необходима для выполнения фрейма. Повышение СУТ является общей функцией всех фреймов и само по себе не определяет линию. Реактивные фреймы индексируются прежде всего по проблемным ситуациям, а линия источника проблемы добавляется там, где она определима.
