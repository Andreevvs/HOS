# Решение проблем

**Класс:** техника HOS

Два поднаправления:

- **РЭП** — техники решения эмоциональных проблем;
- **РСП** — техники решения социальных проблем.

РЭП в существующих материалах HOS проработаны существенно подробнее. РСП следует считать менее разработанным разделом и не достраивать до симметричной системы без опоры на источники или отдельного авторского решения.

Важно отличать РЭП от краткого эмоционального фрейма: наличие негативной эмоции само по себе ещё не делает воздействие техникой решения эмоциональной проблемы.
