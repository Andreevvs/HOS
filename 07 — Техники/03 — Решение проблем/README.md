# Решение проблем

**Класс:** техника HOS

Два поднаправления:

- **РЭП** — техники решения эмоциональных проблем;
- **РСП** — техники решения социальных проблем.

РЭП в существующих материалах HOS проработаны существенно подробнее. РСП исторически было только намечено и не должно достраиваться до симметричной с РЭП системы без опоры на источники или отдельного авторского решения.

## РЭП

См. **«РЭП — Решение эмоциональных проблем»** и **«Размышление чувств — алгоритм HOS»**.

### Архитектурная граница РЭП и фреймов

**РЭП — набор целостных реактивных техник, применяемых при возникновении эмоциональных проблем.** РЭП не является семейством фреймов и не должен декомпозироваться на F-коды только потому, что внутри отдельной техники можно выделить короткие действия или операции.

Краткий реактивный эмоциональный фрейм и техника РЭП — разные классы техники HOS:

- **реактивный фрейм** — локальная короткая операция, применяемая здесь и сейчас для изменения СУТ;
- **техника РЭП** — целостный способ работы с уже возникшей эмоциональной проблемой, который может включать несколько действий, правил или операций.

Совпадение отдельного действия внутри РЭП с действием существующего фрейма не превращает всю технику РЭП во фрейм и не является основанием создавать новый F-код.

Наличие негативной эмоции само по себе ещё не делает воздействие техникой решения эмоциональной проблемы: классификация определяется структурой и назначением техники.

**Авторское решение:** 2026-08-28 — РЭП не разбирать на фреймы; рассматривать как набор целостных техник решения возникших эмоциональных проблем.

## РСП

См. **«РСП — Решение социальных проблем»**.

### Архитектурная граница РСП

**Социальная проблема (СП) — не проблема коммуникации.** Это комплекс взаимосвязанных жизненных задач, ограничений и дефицитов ресурсов, который в совокупности воспринимается человеком как практически неразрешимый и может приводить к перегрузке, снижению СУТ/энергии, пассивности и дальнейшему ухудшению ситуации.

Отдельные задачи внутри СП могут быть разрешимы; проблема возникает из-за их взаимного блокирования и недостатка ресурсов для одновременного решения.

Коммуникация, переговоры, границы, конфликт, компромисс и социальная поддержка могут быть инструментами решения отдельных задач внутри СП, но не определяют класс РСП.

**Авторское уточнение:** 2026-09-10 — РСП трактовать как техники решения комплексных социальных жизненных проблем; тема в исторических материалах только намечена и требует дальнейшей разработки.
