# Перманентные практики

**Класс:** техника HOS

Перманентные практики — длительные или регулярно выполняемые воздействия, целью которых является устойчивое изменение человека и прежде всего его ИУТ.

Граница с фреймами: фрейм ориентирован на короткое ситуативное воздействие; перманентная практика организует повторяющееся или длительное изменение.

Конкретный состав практик требует инвентаризации исходных материалов.
