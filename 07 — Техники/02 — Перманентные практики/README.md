# Перманентные практики

**Класс:** техники HOS  
**Каноническое определение:** [[01 — Канон/Перманентные практики HOS]]

**Перманентная практика HOS** — практика, которая не предназначена для отдельной ситуации, а должна становиться постоянным способом организации жизни и психической деятельности человека.

Граница с ситуативными техниками: ситуативная техника применяется к отдельной задаче или ситуации; перманентная практика должна становиться постоянным способом организации жизни и психической деятельности.
