# Сайт проекта HOS

Материалы, предназначенные для публичного сайта проекта.

## Разделы

- `Книга/` — материалы книги, включая актуальное оглавление.

## Автоматическая синхронизация книги

Изменения в `Книга/Части/` могут запускать существующий workflow синхронизации в `hos-web` через отдельный GitHub App. Настройка доступа, Variables/Secrets и диагностика описаны в [инструкции](../docs/book-sync-dispatch.md).
