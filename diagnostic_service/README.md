# HOS Service — Express Diagnostic v0.1

Экспресс-сценарий выполняет канонический `Экспресс-тест уровня развития v0.1` через `web UI → ProtocolExecutor → KnowledgeService.exact() → Canonical KB`.

Канонические вопросы не копируются в приложение. Новый сеанс получает `whole_document`, проверяет Q1–Q12 и фиксирует `protocol_text`, `source_path` и `source_sha` на время сеанса.

Итог — предварительная гипотеза L и соответствующий диапазон ИУТ. L5 (60–80) разрешён как предварительная гипотеза при согласованно высокой конфигурации Q3/Q5/Q6/Q7/Q9; уверенность ограничена, поскольку Кр5 проверяется только косвенно. L6 экспресс-тестом не диагностируется. ИУТ не вычисляется средним или взвешенной суммой.

UI хранит итоговый результат отдельно от текущего feedback-вопроса: после Q12 результат остаётся видимым на всех трёх шагах обратной связи.

Локальный запуск: `python -m diagnostic_service.web`. Проверки: `python -m unittest discover -v`.

Текущие ограничения: сессии in-memory; экспресс-самооценка не подтверждает прохождение кризисов; публичный deployment не входит в этот локальный прототип.
